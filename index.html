Conectar ao Google Sheets

1. No Apps Script da planilha, adicione esta função:

function doGet() { const ss = SpreadsheetApp.getActiveSpreadsheet(); const aba = ss.getSheetByName("Ranking"); const dados = aba.getDataRange().getValues(); const resultado = dados.slice(1).map(r => ({ pos: r[0], id: r[1], nome: r[2], pts: r[3] })); return ContentService .createTextOutput(JSON.stringify(resultado)) .setMimeType(ContentService.MimeType.JSON); }

2. Clique em Implantar → Nova implantação → App da Web

3. Em "Quem tem acesso" selecione "Qualquer pessoa" e copie a URL

4. Cole a URL no campo da página e clique em Carregar
